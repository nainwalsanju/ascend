# Senior Full-Stack Systems Engineer (Product & Platform)

**Company Profile:** High-Growth YC AI & Cloud Platform ($50M+ Series B)  
**Location:** Remote (US/Global)  
**Target Compensation:** $160,000 – $240,000 Base + 0.1%–0.3% Equity  

### Role Overview
We are looking for an experienced Senior Full-Stack Engineer who thrives at the intersection of robust distributed backends and slick, performant client interfaces. You will build user-facing platforms, real-time collaboration engines, and scalable API gateways supporting millions of active developers and enterprise users.

### Key Responsibilities
- Architect and develop end-to-end full-stack applications using TypeScript/React/Next.js on the frontend and Python/Go/Node.js on the backend.
- Design low-latency REST and GraphQL APIs, asynchronous event workers, and real-time WebSocket communication channels.
- Implement robust state management, server-side rendering, and performance optimizations ensuring <100ms client interactions.
- Manage data pipelines with PostgreSQL, Redis, and Elasticsearch/OpenSearch for real-time search and analytics.
- Automate deployment pipelines using Docker, GitHub Actions, and Kubernetes on AWS.
- Mentor junior and mid-level engineers, conduct architecture design reviews, and establish engineering best practices.

### Qualifications & Requirements
- 4+ years of professional full-stack development experience building scalable SaaS web applications.
- Expertise with TypeScript, React/Next.js, and backend stacks (Python FastAPI/Django or Go).
- Strong command of SQL performance tuning, database migrations, and Redis caching layers.
- Solid grounding in distributed systems fundamentals, concurrency, and idempotent API design.
- Familiarity with CI/CD, containerization (Docker), and automated testing frameworks.
