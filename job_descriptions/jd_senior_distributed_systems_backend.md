# Senior / Staff Backend & Distributed Systems Engineer

**Company Profile:** Tier-1 FinTech / Infrastructure Leader (Similar to Stripe, Databricks, Ramp)  
**Location:** Remote / San Francisco, CA / New York, NY  
**Target Compensation:** $180,000 – $265,000 Base + Significant Equity  

### Role Overview
We are looking for a Senior / Staff Backend Engineer to design, build, and scale our mission-critical distributed systems. You will own core processing pipelines handling tens of thousands of requests per second (RPS), optimize tail latencies across global microservices, and design high-throughput data processing engines with strict reliability guarantees.

### Key Responsibilities
- Architect, build, and maintain low-latency, high-throughput microservices using Go, Python, or Java.
- Scale distributed streaming and messaging architectures using Apache Kafka, RabbitMQ, or AWS SQS/SNS.
- Optimize relational and distributed databases (PostgreSQL, CockroachDB, DynamoDB) via schema normalization, query profiling, and index strategies.
- Implement distributed caching and rate-limiting tiers (Redis, KeyDB) to achieve sub-10ms p99 latency at scale.
- Lead system architecture decisions, data consistency models, and fault-tolerant mechanisms (idempotency, circuit breakers, backpressure).
- Collaborate with infrastructure and SRE teams to deploy containerized workloads across Kubernetes and AWS/GCP environments.
- Champion engineering excellence through rigorous code reviews, automated unit/integration testing, and CI/CD pipelines.

### Qualifications & Requirements
- 5+ years of software engineering experience building production-grade backend distributed systems.
- Strong proficiency in at least one modern backend language: Go, Python, Java, or C++.
- Proven experience scaling systems to 50,000+ QPS/RPS and sub-20ms p99 response times.
- Deep understanding of distributed transactions, asynchronous architectures, and eventual consistency.
- Hands-on experience with cloud infrastructure (AWS/GCP), Docker, and Kubernetes.
- Experience reducing cloud infrastructure expenditure and optimizing resource utilization.
- Track record of driving engineering projects from conceptual design through production launch.
